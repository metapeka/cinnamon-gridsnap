# Апплет Cinnamon для GridSnap

Панельный апплет `gridsnap@metapeka` — быстрый доступ к установленному GridSnap:
список зон, применение зоны к активному окну, профили раскладок, редактор сетки,
установка сочетаний клавиш и сводка по рабочим областям. Апплет не содержит своей
логики раскладки: он зовёт существующие скрипты (`zone-tiler.py`,
`zone-editor.py`, `setup-hotkeys.py`, `gridsnap-ctl`) из каталога, указанного
в настройках.

Если включена надпись в панели, к ней добавляется зона активного окна
(`GridSnap — main`) — см. «Индикатор текущей зоны».

## Установка

1. Скопировать каталог апплета в пользовательский каталог Cinnamon:

   ```bash
   mkdir -p ~/.local/share/cinnamon/applets
   cp -r contrib/applet/gridsnap@metapeka ~/.local/share/cinnamon/applets/
   ```

2. Открыть «Апплеты» и включить GridSnap:

   ```bash
   cinnamon-settings applets
   ```

   Либо перетащить иконку GridSnap на панель. Апплет появится в списке как
   **GridSnap**.

3. Проверить настройку «Каталог GridSnap» (правый клик по апплету →
   «Настроить…»): по умолчанию это `~/thinkrail/gridsnape`. Если GridSnap
   поставлен пакетом, укажите каталог с кодом (например, `/usr/lib/gridsnap`)
   либо свой рабочий каталог из репозитория.

Обновление — заново скопировать каталог поверх:

```bash
cp -r contrib/applet/gridsnap@metapeka ~/.local/share/cinnamon/applets/
```

Удаление:

```bash
rm -rf ~/.local/share/cinnamon/applets/gridsnap@metapeka
```

## Что в меню

Меню открывается и по левому, и по правому клику (по правому к нашим пунктам
добавляются стандартные «О приложении»/«Настроить…»/«Удалить» от Cinnamon).

| Пункт | Что делает |
|---|---|
| Открыть редактор | `python3 zone-editor.py` — визуальный редактор сетки |
| Применить сочетания | `python3 setup-hotkeys.py` — регистрирует `[keys]` в Cinnamon |
| Зоны (подменю) | список из `zone-tiler.py list`; клик по зоне — `zone-tiler.py apply <зона>` к активному окну |
| Профили (подменю) | список из `zone-tiler.py profile list`; клик по профилю — `zone-tiler.py profile use <имя>` (активирует профиль и перерегистрирует сочетания) |
| Рабочие области (подменю) | сводка из `zone-tiler.py list --monitor N` по каждому монитору Cinnamon |
| Разложить окна по правилам | `zone-tiler.py arrange` |
| Отменить последнюю раскладку | `zone-tiler.py undo` |

Список зон, профилей и рабочих областей обновляется каждый раз при открытии меню.

В подменю «Профили» пустой список — это неактивная строка «Профилей нет»,
а упавший `profile list` — неактивная строка с причиной из его вывода (молчания
не бывает). Активация профиля работает через `profile use` и поэтому сама
перерегистрирует сочетания клавиш; отдельного пункта «без сочетаний» в апплете
нет.

## Индикатор текущей зоны

Если включена надпись в панели (`use-label`), апплет раз в 2 секунды смотрит,
в какой зоне активное окно, и дописывает её к надписи: `GridSnap — main`.
Та же зона видна в тултипе («Текущая зона: main»). Отдельного переключателя
у индикатора нет: он часть надписи.

Как апплет это узнаёт:

1. `xprop -root _NET_ACTIVE_WINDOW` — id активного окна (пакет `x11-utils` уже
   в зависимостях пакета GridSnap);
2. `<python-bin> <каталог>/gridsnap-ctl status` — JSON состояния демона, поиск
   окна по полю `windows[].window` и взятие его `zone`.

Условия и границы:

* опрос идёт только когда надпись включена и апплет есть в панели; при
  выключенной надписи таймера нет вовсе (значит, и в тултипе зоны нет);
* на время открытого меню опрос пропускается — меню и так зовёт CLI;
* демон не запущен, `xprop` нет, ответ не разобрался или окна нет в списке —
  индикатор просто молчит (надпись остаётся `GridSnap`, тултип обычный),
  никаких уведомлений и ошибок в панели не появляется;
* таймер снимается в `on_applet_removed_from_panel`, поэтому выключение
  апплета не оставляет опросов демона.

## Настройки апплета

| Ключ | Тип | По умолчанию | Зачем |
|---|---|---|---|
| `gridsnap-dir` | каталог | `~/thinkrail/gridsnape` | каталог, из которого запускаются скрипты GridSnap |
| `python-bin` | строка | `python3` | интерпретатор для скриптов |
| `use-label` | переключатель | выкл | показывать ли надпись рядом с иконкой (вместе с индикатором зоны) |
| `label-text` | строка | `GridSnap` | текст надписи; индикатор дописывается через « — » |

Почему каталог по умолчанию именно `~/thinkrail/gridsnape`: это рабочая установка
автора GridSnap (см. `README.md` репозитория, раздел «Для себя»). Для пакетной
установки каталог кода — `/usr/lib/gridsnap`, поэтому его стоит указать вручную:
апплет не угадывает, где лежит GridSnap, а следует настройке.

## Как это устроено

* Апплет — тонкая обёртка над CLI: он не читает `zones.conf` и не знает формата
  секций, поэтому изменения в GridSnap не требуют правки апплета.
* Вывод `zone-tiler.py list` разбирается двумя регулярными выражениями
  (строка рабочей области и строки зон). Если формат вывода когда-нибудь
  изменится, подменю «Рабочие области» покажет первую строку как есть, а список
  зон — сообщение об ошибке, но сам апплет продолжит работать.
* Запуск скриптов — через `Gio.Subprocess` (асинхронно, не блокируя Cinnamon) и
  `Util.spawn` для «запустить и забыть» (редактор, установка сочетаний).
* Индикатор зоны — `GLib.timeout_add_seconds` (2 с) плюс те же `Gio.Subprocess`
  для `xprop` и `gridsnap-ctl`; никаких новых зависимостей у апплета нет.
  Пока предыдущий опрос не ответил, следующий не запускается, поэтому
  медленный демон не копит процессы.
* Иконка панели — `icon.png` из каталога апплета; если файла нет, берётся
  символическая иконка темы `view-grid-symbolic`.

## Ограничения

* Апплет проверялся на Cinnamon 6.4 (GJS). В `metadata.json` указаны версии
  `6.0`, `6.2`, `6.4`.
* Применение зоны идёт к активному окну (`_NET_ACTIVE_WINDOW`) — это то же
  поведение, что у горячих клавиш GridSnap; отдельного выбора окна в апплете нет.
* Индикатор показывает зону только для окон, которые демон уже знает: окно,
  к которому зону ещё не применяли, индикатора не даёт (это не ошибка, а
  отсутствие данных).
