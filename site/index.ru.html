Gridsnap

Сетка окон для Cinnamon: нарисуйте свои зоны и кладите окна в них одной клавишей.

Установить

Что умеет

  • Визуальный редактор зон — зоны перетаскиваются прямо по картинке экрана: сколько угодно, у каждой имя и клавиша; размеры хранятся долями рабочей области, поэтому сетка не ломается при смене разрешения и оставляет место панели.
  • Окно в зону по клавише — раскладчик ставит активное окно пиксель в пиксель: снимает максимизацию и компенсирует рамку окна (_NET_FRAME_EXTENTS) через EWMH-сообщения muffin.
  • Демон и автоукладка — появившиеся окна встают в зоны по правилам из zones.conf ([rules]), вынесенное вручную окно остаётся где поставили, а освободившаяся зона может расшириться в соседнюю.
  • Вкладки в зоне — несколько окон одной зоны не громоздятся друг на друга: сверху зоны появляется полоса с их заголовками, а переключает их клавиша или клик.
  • Режим «только эта зона» — одна клавиша кладёт окно в зону и сворачивает остальные окна этого стола и монитора; та же клавиша возвращает их на место.
  • Горячие края — тащите окно за заголовок: сетка подсвечивает зону под курсором, и на отпускании окно встаёт в неё.
  • Выбор зоны по Super+Z — оверлей с вашими зонами: стрелки двигают выделение, Enter кладёт окно, Esc отменяет.
  • Действия — своя клавиша: встроенные (свернуть остальные, показать окно зоны, терминал в зоне, обмен двух зон) или ваша команда, которой передаются окно, зона и её рамка.
  • Несколько мониторов — у каждого экрана своя сетка, зона ищется в профиле того экрана, где окно, а другие экраны не трогаются.
  • Профили на экран и на стол — «монитор 2 — кино», стол 1 — работа: раскладка переключается одной клавишей.

Снимки

Установка

Два независимых пути: из репозитория, для себя, или пакетом. Ставится один и тот же код; кроме python3, PyGObject и libX11 ничего не нужно.

Из репозитория:

./install-launcher.sh             # ярлык в меню + иконки
./install-launcher.sh --desktop   # ещё и ярлык на рабочем столе
./install-daemon.sh               # автозапуск демона автоукладки
python3 setup-hotkeys.py          # сочетания клавиш в Cinnamon

Пакетом (.deb для Debian/Ubuntu, AUR-рецепт для Arch, .tar.gz для любой системы):

make tarball      # dist/gridsnap-<версия>.tar.gz
make deb          # dist/gridsnap_<версия>_all.deb
make aur          # AUR-рецепт в dist/PKGBUILD

sudo apt install ./dist/gridsnap_<версия>_all.deb

Полная инструкция, формат конфига и все команды — в документации.
