Gridsnap

Cinnamon（X11）上的窗口网格：自己画区域，用快捷键把窗口放进去，其余交给守护进程。

安装

它能做什么

  • 区域编辑器：在屏幕画布上画网格 —— 拖动和缩放区域、吸附到边缘和 1/4、1/3、1/2 线、模板、自己的方案。
  • 一个键把窗口放进区域：每个区域一个快捷键（默认 Super+Alt+1..4），窗口像素级落进区域，连窗口边框一起补偿。
  • 守护进程自动布局：新窗口按 [rules] 规则（WM_CLASS 或标题）自己进区域，不用手点。
  • 区域内的标签页：区域里的第二个窗口不会叠成一堆，而是变成标签页，区域上方出现标签条。
  • 「只留这个区域」模式：一个键把窗口放进区域，并最小化同一桌面、同一显示器上的其他窗口，再按一次还原。
  • 热区：抓住标题栏往网格上拖，网格出现并高亮，松手窗口就位。
  • 选择器 Super+Z：覆盖层上用方向键选区域，Enter 放入窗口，Esc 取消。
  • 动作：把自定义命令绑到按键（[action:<名字>]），命令能拿到窗口、区域和像素范围。
  • 多显示器：每台屏幕有自己的区域集合和方案（[monitors]），窗口在它所在的那台屏幕上布局。
  • 方案：布局按屏幕和按工作桌面保存（[workspaces]），一条命令或一个按键就能切换。

安装

两条互相独立的路径，装的是同一份代码；版本号取自 zone-tiler.py/zone-daemon.py 里的 VERSION。

自己用（从仓库安装）

除了 python3、PyGObject 和 libX11（Debian 里已经装好）什么都不需要：

./install-launcher.sh             # 菜单里的快捷方式和图标
./install-launcher.sh --desktop   # 再加一个桌面快捷方式
./install-daemon.sh               # 自动启动自动布局守护进程
python3 setup-hotkeys.py          # 在 Cinnamon 中注册快捷键

以软件包安装

Debian/Ubuntu 用 .deb，Arch 用 AUR 配方，发布版 .tar.gz 适用于任何系统：

make deb          # dist/gridsnap_<版本>_all.deb
sudo apt install ./dist/gridsnap_<版本>_all.deb

make tarball      # dist/gridsnap-<版本>.tar.gz
tar -xzf gridsnap-<版本>.tar.gz && cd gridsnap-<版本>
./install.sh      # ~/.local：代码、命令、菜单快捷方式、图标

守护进程、zones.conf 和各种标志的完整说明见 README。
